# CheckAI, задание 1: атака на линейную модель своими руками

Логистическая регрессия на чистом numpy (MNIST, цифры 3 и 7), обучение градиентным спуском
и атака FGSM на неё.

## Что внутри

- `AI.py` — код: загрузка данных, обучение, оценка accuracy, визуализация весов,
  FGSM, график accuracy(ε), примеры атакованных изображений, сравнение возмущения с весами.
- `JOURNAL.md` — журнал решений.
- Ноутбук с отчётом (формулы, предсказания перед экспериментами, выводы).

## Запуск

1. Создать окружение и поставить зависимости:

   ```
   python -m venv venv
   venv\Scripts\activate
   pip install numpy matplotlib
   ```

2. Положить MNIST в формате CSV (первая колонка — метка, далее 784 пикселя):

   ```
   mnist_train/mnist_train.csv
   mnist_test/mnist_test.csv
   ```

   Файлы не хранятся в репозитории (см. `.gitignore`).

3. Запустить:

   ```
   python AI.py
   ```

## Ограничения задания

Модель, обучение и атака написаны только на numpy. torch, sklearn и подобные библиотеки не используются.
